# ADR 004 — Operis UI

**Contexto:** contabilidade exige leitura densa, consistência e ações explícitas.

**Decisão:** tokens semânticos graphite/bone/jade/violet, Geist, componentes próprios com CVA e primitives Radix. Light padrão, dark/system e duas densidades.

**Alternativas:** biblioteca visual fechada, estilos independentes por página, tema branco/azul genérico.

**Consequências:** identidade controlada e expansão gradual. Componentes adicionais entram quando houver uso, evitando uma biblioteca extensa sem consumidores.
