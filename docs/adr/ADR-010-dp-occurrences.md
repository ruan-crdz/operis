# ADR-010: Movimentações operacionais de DP

**Status:** aceito.

Movimentações são entidades tipadas com origem, data efetiva, colaborador opcional e chave idempotente. Texto livre fica restrito a notas. CPF não identifica registros e não entra em auditoria. A estrutura preserva lineage sem assumir regras de cálculo de folha.
